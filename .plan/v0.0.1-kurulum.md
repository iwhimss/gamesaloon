## Kapsam (bu sürümde ne var, ne yok)

**Var:**
- Backend iskeleti (Node.js + Express + Socket.io) — "merhaba dünya" seviyesi + health check.
- Frontend iskeleti (React + Vite) — backend'e socket ile bağlanıp bağlantı durumunu gösteren tek sayfa.
- PostgreSQL + Redis, Docker Compose ile ayağa kalkar (Redis en baştan dahil — kullanıcı kararı).
- DB migration altyapısı ve taslak şema (users, tables, table_players, game_sessions, score_history) — tablolar oluşur ama iş mantığı (lobi, masa, oyun) henüz yok.
- Misafir modu kullanıcı sistemi: isim gir → misafir kullanıcı oluşur → basit oturum (JWT, guest flag'li).
- Versiyon bilgisi: kök `package.json` + `CHANGELOG.md`'de `0.0.1` olarak işaretlenir.
- README güncellemesi (kurulum adımları, mimari özeti, çalıştırma komutları).
- Git init + GitHub'a ilk push.

**Yok (v1'in sonraki sürümlerine — v0.1.0+ — bırakılıyor):**
- Lobi/masa listeleme, masa kurma/katılma, host yetkileri.
- Okey oyun motoru ve arayüzü.
- Puan sistemi, oturum sonu ekranları.
- PWA (manifest, service worker).
- Gerçek (şifreli) kullanıcı kaydı — sadece misafir modu var.
