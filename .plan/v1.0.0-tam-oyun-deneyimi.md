## Kapsam

**Bu sürümde tamamlanacak (roadmap 3-8):**
- Lobi + masa (oda) sistemi — masa kurma/katılma, kod+şifre, oda listesi
- Host yetkileri — oyunu başlatma, oyuncu atma, ayar değiştirme, hostluk devri, otomatik devir
- Okey oyun motoru (backend, saf fonksiyonlar) — 106 taş, gösterge/okey belirleme, çekme/atma, el bitirme, temel puanlama
- Okey frontend arayüzü — oyun masası, taş görselleri, sıra göstergesi, sürükle-bırak
- Puan sistemi ve oturum sonu ekranları
- PWA (manifest, service worker, "ana ekrana ekle")
- **Kapsamlı tasarım/stil geçişi**: sade, göze hoş, büyük/net tipografi, yüksek kontrast — yaşlı kullanıcılar dahil herkesin kolayca kullanabileceği bir arayüz. Lobi, giriş, masa, oyun ekranlarının tamamına uygulanacak.

**Bu sürümde YAPILMAYACAK (kullanıcı onayıyla netleşti):**
- Gerçek VDS'e deploy (SSH erişimi yok) — sadece **hazırlık dosyaları** üretilecek: `docker-compose.prod.yml`, nginx reverse proxy config örneği, Certbot adımları, `.env.production.example`. Gerçek sunucuya yükleme kullanıcı tarafından yapılacak.
- Gerçek (şifreli) kullanıcı kaydı — misafir modu v0.0.1'de zaten var, bu sürümde dokunulmuyor.
- Minigame/güç kartları/emoji gibi v2+ özellikleri (orijinal plan dosyasında da net şekilde dışlanmış).

- [x] Host ayrılırsa otomatik en kıdemli oyuncuya devir (Faz A'da zaten vardı, doğrulandı)
- [x] Yetki kontrolü: host olmayan kullanıcıdan gelen host komutları reddedilir (ack callback ile `{ok:false, error}`)
- [x] Frontend: host'a özel kontrol paneli (masa içi: at/host yap/şifre değiştir), diğer oyunculara host rozeti gösterimi
- **Uçtan uca test edildi** (2 misafir): kick çalıştı ve atılan kullanıcı lobiye döndü, host devri çalıştı (kontroller doğru taraf değiştirdi), şifre güncelleme çalıştı (🔒 rozeti belirdi)
- **Kritik bug bulundu ve düzeltildi**: atılan/ayrılan bir kullanıcı aynı masaya tekrar katılınca `table_players` üzerinde `(table_id, user_id)` unique constraint çakışması backend'i **çökertiyordu** (yakalanmamış promise rejection). Düzeltme: `INSERT ... ON CONFLICT DO UPDATE` (upsert) + tüm oda/host socket handler'larına try/catch + `index.js`'e global `unhandledRejection` güvenlik ağı eklendi. Yeniden test edildi, sorun yok.

## Faz C — Okey Oyun Motoru (Backend, Saf Fonksiyonlar) ✅ (2026-07-30)
- [x] `backend/src/games/okey/` modülü: `createGame`, `handleAction`, `getStateForPlayer`, `isGameOver`, `calculateScore` (plan dosyasındaki plugin arayüzü)

- [x] Socket entegrasyonu: `game:start` (host-only), `game:action` ({draw|discard|finishHand}), sunucu → `game:state` (SADECE kendi eli, per-socket), `game:handEnded`
